## 🎯 The Studio

**Senvon Atelier** was established in 2025 — but the practice behind it goes back to 2023. A handful of years of solo and small-team builds for hospitality, education and commerce clients, sharpening how we approach software before putting a name on it.

We are a tight, remote-first team out of **Accra, Ghana**, partnering with founders and small institutions alike. We stay deliberately small so every project gets senior attention — and so the work stays something we are proud to sign.

**A small atelier with the range of a much larger one.**

## 🧪 Our Products

*We don't only build for clients.* Running a studio surfaces problems worth solving twice. These are the in-house tools we turned into products — each used on our own work before it shipped to anyone else.

### **Home Sweet Home** — *In Active Development*
> *Property management software for landlords and property managers*

One tool for tenants, leases, payments and the day-to-day chaos of running a portfolio.

**Under the hood:** a Go core API, a dedicated Hono authentication service, a TypeScript web client and a Flutter mobile app — separated so each can be scaled and reasoned about on its own.

**The studio, used as its own toughest client.**
