## 🎯 关于工作室

**Senvon Atelier** 成立于 2025 年，但支撑它的实践可追溯到 2023 年——数年间以独立或小团队的方式，为酒店、教育与商业领域的客户交付项目，在为它命名之前，先把做软件的方式打磨清楚。

我们是一支扎根于**加纳阿克拉**、远程优先的精简团队，既服务创业者，也服务小型机构。我们刻意保持小规模，好让每个项目都得到资深工程师的关注——也让每一件作品都值得我们署名。

**小而精的工作室，具备大型团队的覆盖面。**

## 💎 我们做什么

### **定制软件** — *围绕你的业务而建*
> *架构 · API · 系统*

依据你的业务真实的运转方式来设计平台与内部工具，而不是照模板的假设来做。

***

### **Web 应用** — *从 MVP 到平台*
> *React · Astro · 云*

快速、可访问、可扩展的 Web 产品。从第一版 MVP 起步，无需重写即可成长为生产级平台。

***

### **移动应用** — *一套代码，两个平台*
> *iOS · Android · React Native · Flutter*

用一套可维护的代码库，交付接近原生体验的 iOS 与 Android 应用。

***

### **AI 与机器学习** — *经得起真实用户检验*
> *大模型 · RAG · 自动化*

大模型功能、自动化与轻量数据管道，能够经受真实用户与真实预算的考验。

***

### **云与 DevOps** — *从容发布*
> *Cloudflare · CI/CD · 基础设施*

有韧性的基础设施、持续交付与可观测性，让上线不再是一件大事。

***

### **产品与设计** — *化繁为简*
> *UX · UI · 设计系统*

以研究为先导的产品策略与界面设计，让复杂的东西用起来理所当然。

## 🧪 自有产品

*我们不只为客户做开发。* 经营一间工作室，会让一些值得解决第二次的问题浮出水面。这些是我们把内部工具做成的产品——每一个都先在自己的项目里用过，才交到别人手上。

### **Home Sweet Home** — *开发中*
> *面向房东与物业管理者的房产管理软件*

用一个工具处理租户、租约、收付款，以及管理房产组合的日常琐碎。

**技术构成：** Go 编写的核心 API、基于 Hono 的独立认证服务、TypeScript Web 客户端与 Flutter 移动端——各自拆分，便于独立扩展与理解。

**把工作室当成自己最挑剔的客户。**
